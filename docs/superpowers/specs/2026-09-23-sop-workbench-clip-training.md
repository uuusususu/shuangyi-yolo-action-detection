# 工作台「放入动作」就能认出进 / 1–4 / 出

日期：2026-09-23  
目标：工作台放入 Hands + YOLO，再按动作放入样本，稳定识别进来、步骤 1–4、出去；中途离开可报错。  
不是：同一类别散图文件夹。

## 1. 你要的用法，对的是哪一种「放入」

| 放入什么 | 能不能训出稳定步骤识别 |
| --- | --- |
| 散图文件夹（都叫 act1） | 不能。没有时间，刚伸手就会过 |
| **每个动作若干段连续视频 / 按时间编号的连续帧** | **能。** 这是工业里的标准工作台 |

「放入这个动作」= 放入**这一步从开始到结束的整段录像**（或连续图），不是一堆单张照片。

## 2. 全网已有的同类做法

| 来源 | 怎么训 | 怎么认 |
| --- | --- | --- |
| [AI-SOP](https://github.com/xiabie666/AI-SOP)（84★） | 装配视频 + 时间轴；YOLO+Hands 抽特征；LSTM | 当前步骤 + 顺序 + 连续命中帧 |
| [51CTO：视频切成动作片段](https://blog.51cto.com/zhangxueliang/14869857) | 先采整段，再切成动作 clip，LSTM 认片段 | 动作识别 + SOP 状态机 |
| [NVIDIA sop-monitoring-blueprints](https://github.com/NVIDIA/sop-monitoring-blueprints)（61★） | 整段视频标起止，切成 action chunks，再训分割 | 时序检测 + 步骤合规 |
| 产线 SOP 引擎（连续确认帧） | 每步动作类 + 最少停留帧 | 状态机，未完成离开可 NG |

弱监督（只给整段视频一个名字、自动切边界）学术上有，工位少样本不稳定，**不建议**当第一方案。

结论：别人工作台也是「每步放视频/连续片段」，再加状态机做稳定和报错。没有「散图 + 两个模型」直接出因果 TCN 的成熟方案。

## 3. 工作台应长什么样

一次配置：

1. 放入 **MediaPipe Hands**、**YOLO OBB**（只推理）  
2. 建流程：`enter → act1 → act2 → act3 → act4 → exit`  
3. 每个节点放入 **该步的连续样本**（mp4，或 `0001.jpg…0200.jpg`）  
   - enter：人进来、靠近工位，多条  
   - act1–4：该步从动手到做完，多条  
   - exit：人离开，多条  
   - 建议再放：只做完前几步就走、空闲工位  
4. 点训练：只训因果 TCN（或先 LSTM）  
5. 运行：滑窗认当前步 + 状态机推进 / 报错  

每个 clip 整段标签就是这一步。工作台自动：逐帧跑 YOLO+Hands → 特征序列 → 该步类名。

## 4. 这样怎样训出因果模型

每个 clip 是短序列，本来就有前后帧。

- 从 `act2/video_03.mp4` 抽 `T×F` 特征，标签全是 `act2`（或窗标签 = act2）  
- 因果 TCN：第 t 帧只看本 clip 里 ≤t 的特征  
- 7 类：`idle / enter / act1 / act2 / act3 / act4 / exit`  
- 窗长盖住**单步**（64 帧量级），不必一条 clip 盖住从进到出  

和「一条长视频标满时间轴」监督等价，只是工作台按步收 clip，更符合「放入这个动作」。

完整一轮从进到出的长视频也可以再导入，自动按时间轴当 6 段，效果更好，不是必须。

## 5. 运行时怎么稳定认、中途走怎么报错

不做「看见类名就过」。

```text
等 enter：滑窗连续 K 帧是 enter → 进入 act1
等 act1：连续 K 帧是 act1 → 进入 act2
…
等 act4 完成后等 exit：连续 K 帧是 exit → 整轮 PASS

等 act3 时连续 K 帧是 exit → NG（做完前面就出去）
等 act2 时连续是 act4 → NG（跳步）
```

K = 现有通过稳定帧。这就是「稳定识别」。

## 6. 每步建议放多少

| 节点 | 连续片段条数 |
| --- | --- |
| enter / 每个 act / exit | 各 20–40 条（不同人、快慢） |
| 空闲 / 只进来就走 / 做到一半走 | 各 10–20 条 |

Hands、YOLO 不在工作台里重训。换步骤只加 clip、重训 TCN。

## 7. 和本仓库的关系

感知已有：同帧 YOLO + Hands。缺的是：按步收连续片段、特征序列、因果头、SOP 状态机。  
工作台第一刀只做「导入 clip → 抽特征 → 训 TCN」，判定仍可后接现有步骤引擎。
