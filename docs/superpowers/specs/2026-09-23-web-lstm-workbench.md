# 网页时序训练台

日期：2026-09-23  
状态：方案已定，未开始写代码  
分支：`feature/mediapipe-hands-overlay`  
基线：`main`

这个网页只训练，不检测。工位上的检测程序继续负责现场。训练台跑在同一台电脑上，启动后打开浏览器，只监听 `127.0.0.1`。

## 1. 做什么

工程师放入一条完整视频，或按序号排好的连续图。在这条片子上用多条轨道把步骤时间段标出来。训练台用已经有的 YOLO 和谷歌手部模型逐帧抽出特征，按标好的时间段训练 LSTM，用验证集宏平均 F1 判断这轮能不能试用。导出一个包。不改正在跑的工位程序，也不改它正在用的配置文件。

YOLO 和手部模型不在这里重训。

## 2. 作为完整软件要有的功能

算法规则不够用。下面这些是软件本身必须有的，缺一项就只能算一次实验脚本。

| 功能 | 做什么 | 没有会怎样 |
| --- | --- | --- |
| 工程 | 新建、打开、自动保存。刷新或训练中断后，轨道标注还在 | 标完一段，刷新就没了 |
| 素材入库 | 选中的视频和连续图复制进工程目录，不靠外部路径 | 原文件一挪，无法再抽特征 |
| 类别 | 增加、改名、删除。删除时说明这条轨道上的色块一并删掉 | 类别和已标时间段对不上 |
| 时间轴 | 一个播放头，每类一条轨道。拖色块边缘。放大时间轴，逐帧挪边界 | 长片子上边界误差几十帧，标签是脏的 |
| 任务 | 抽特征和训练在后台跑，页面看进度。失败写出文件名和原因。再次点击无效。停止保留当时最好的一轮 | 点两次开两个任务，或失败了不知道卡在哪 |
| 日志 | 每次任务一份日志：片子、类别、划分、损失、分数 | 三次对比只有一个数，不知道当时用的什么数据 |
| 导出包 | 权重、网络结构、类别顺序、窗长、模型文件指纹、划分清单、验证结果。写在导出目录里 | 工位加载时对不上，而且可能改到正在用的配置 |

## 3. 数据怎么切

一个格子是一条片子，不是一个步骤。点进去之后，从文件夹里选一个视频，或一组按数字序号排好的连续图。连续图按帧号当进度。排序用数字顺序，不用字符串顺序。多条拍摄是多个格子。

画面下面只有一个播放头。每个类别一条轨道。增加一个类别，就多一条轨道。4 个类别就是 4 条轨道。拖的是轨道上色块的左右边缘，不是播放头。点一个色块，播放头跳到这段开头。

```text
播放进度  |--------●--------------------------|
步骤1     |    [====]                        |
步骤2     |            [========]            |
步骤3     |                        [======]  |
步骤4     |                                  |
```

没涂到、并且连续长度达到 48 帧的时间，标成空闲，用来训练和打分。不必再画一条空闲轨道。两段交叠时标红，训练按钮不可用。同一类别两段之间空档短于 48 帧时警告，可以合并成一段。无序散图不能放进来。素材文件缺失时写出路径，不能开始训练。

某个类别涂出的时间段少于 10 段时警告，仍然允许训练。结果页标明「样本不足」。不禁止按钮。每个类别在训练片和验证片里都至少要有一段，否则不能开训。只有一条片子时，训练和验证拆不开，也不能开训。

## 4. 特征

抽特征只写一份代码。训练台调用它。以后工位程序也调用它，不复制第二份。

```text
F = 零件类数 × 5 + 126
```

每个零件类只留置信度最高的一个框：置信度、中心、宽、高，除以画面宽高。低于工位正在用的置信度阈值，或这一类没有框，这 5 个数填 0。手最多两只，每只 21 点的 x、y、z。两只手按画面从左到右放进槽位。没有手的位置填 0。框和手必须来自同一帧。

类名顺序、特征长度、窗长、YOLO 文件指纹、手部模型指纹写进导出包里的契约文件，不写进工位正在用的 `config.json`。顺序或指纹变了，旧权重不能加载。

训练片先重采样到工位相机的帧率，再取 48 帧。分辨率、帧率、机位和工位不一致时，不能开始训练。

手没检到是正常情况，填 0。视频打不开，或 YOLO、手部模型报错，任务停在这个文件，页面写出文件名和错误，不能开始训练。

## 5. 训练

窗长 48 帧，步长 8。一个窗口的标签，是它完全落在哪一段里，包括空闲段。跨过两段边界的窗口丢掉，不标成其中任何一步。短于 48 帧的色块整段丢掉，页面列出文件名和时间。验证集按整条片子划分，同一条片子的窗口不能同时出现在训练和验证里。

网络固定为双层 LSTM，隐层 128，dropout 0.2。读完 48 帧，取最后一帧的摘要，再接到步骤数。损失用交叉熵。优化器用 Adam，学习率 `1e-3`。随机种子固定。保留验证宏平均 F1 最高的一轮。这些写进契约文件，工位按同一结构加载。

已经有任务在跑时，再次点击无效。要重来必须先停止。停止时保留当时验证分数最高的检查点，不把半截权重写成最好的结果。

训练台不检测工位程序是否正在运行，也不做现场检测。训练会占用这台电脑的显卡，由人决定什么时候训。

## 6. 用哪些指数判断好坏

准确率不能单独当标准。样本多的步骤会把准确率抬高。

主指数是验证集宏平均 F1。一条片子里有多步。一段里的窗口概率先取平均，得到这一段的预测，再算宏平均 F1、召回和混淆矩阵。空闲段同样参与，用来看空闲被误报成步骤的比例。

| 指数 | 作用 | 不合格的样子 |
| --- | --- | --- |
| 验证宏平均 F1 | 这轮留不留 | 低于 0.90 |
| 每步召回 | 这一步会不会漏 | 任一步低于 0.85 |
| 空闲误报率 | 空闲被认成某个步骤 | 高于 0.10 |
| 每步精确率 | 会不会认成别的步 | 和召回一起看 |
| 混淆矩阵 | 哪两步互相认错 | 对角线以外成块 |
| 训练损失 / 验证损失 | 有没有只记住训练集 | 训练损失降，验证损失升 |
| 每步段数 | 是模型差还是数据少 | 少于 10 段标成样本不足 |

合格线：验证宏平均 F1 ≥ 0.90，并且每步召回 ≥ 0.85，并且空闲误报率 ≤ 0.10，并且验证损失没有在训练损失下降时抬头。没过就显示「不可试用」。某个步骤在验证集里一段都没有，这轮直接「不可试用」。

结果页点开认错格子，回放跳到分错窗口的起止时间。页面保留最近三次训练的分数，只比较类别名单和特征长度相同的轮次。

「可试用」只表示这批评审片子过了合格线，不是工位已经验收。

## 7. 页面顺序

1. 工程。新建、打开、看到自动保存是否成功。
2. 模型。选定 YOLO 和谷歌手部模型，检查能不能加载，记下文件指纹和置信度阈值。
3. 数据。一条片子一个格子。点进去选视频或连续图，用类别轨道标时间段。显示每类涂了几段。
4. 特征。后台抽出特征。显示特征长度、没检出手的比例、没检出零件的比例。
5. 训练。显示训练损失和验证损失，以及进度。
6. 结果。宏平均 F1、每步召回、空闲误报率、混淆矩阵、合格或不可试用、认错回放、最近三次对比。
7. 导出。下载一个目录：`best_lstm.pt`、契约文件、划分清单、验证结果、任务日志。

轨道交叠、损坏文件、无序散图、素材缺失、相机条件不一致、某个类别无法同时进入训练和验证时，训练按钮不可用。

## 8. 这一版不做

- 网页里录像
- 自动把长视频切成步骤
- 样本太少时禁止训练
- 把权重写进工位程序的配置
- 热替换正在检测的程序
- 重训 YOLO 或手部模型
- 探测工位程序是否正在检测

## 9. 和现有程序的关系

检测、手部骨架、顺序引擎都还在工位程序里。训练台不调用顺序引擎。它只产出导出包。工位程序以后读取同一份抽特征代码和这份包。那是下一次改动，不是这一版。加载时若指纹、类名顺序或网络结构和契约不一致，拒绝使用，不静默换上。
