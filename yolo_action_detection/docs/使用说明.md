# 双翼科技视觉行为引导系统 · 使用说明

程序启动时读取 `config/config.json`。改配置后重启，或在配置页点保存后才会生效。

便携版把整个 `YOLOActionDetection` 文件夹一起用，配置在包内 `config/config.json`。不要只拷 EXE。

---

## 1. 配置文件怎么用

`config.json` 是运行参数。日常要改的主要是这几项：

| 字段 | 作用 |
| --- | --- |
| `yolo_model_path` | 模型文件（`.onnx` 或 `.pt`） |
| `yolo_conf_threshold` / `yolo_iou_threshold` | 置信度、IoU |
| `category_names` / `category_counts` | 待检类别名和数量。名称必须和模型类别完全一致 |
| `mvsdk_camera_sn` | 相机序列号 |
| `action_order_constraint_enabled` | 关掉 ROI 时，打开则用连续 LSTM 判完整动作；关掉则仍按 YOLO 步骤 |
| `lstm_bundle_path` | 动作模型包目录。顺序模式必填，里面要有 `best_lstm.pt`、`contract.json`、`runtime_manifest.json` |
| `action_pass_stable_frames` / `action_ng_stable_frames` | YOLO 步骤的通过 / NG 连续帧数。连续动作不再套用这两项 |
| `round_cooldown_seconds` | 一轮结束后到下一轮的间隔（秒） |
| `roi_inspection_enabled` | 是否走 ROI 定位检测 |
| `roi_template_enabled` | 是否用模板匹配定位 |
| `roi_inspection_rect` | 识别 ROI（绿框，统计类别数量） |
| `roi_template_rect` | 模板 ROI（青框，只在创建模板时裁这块图） |
| `roi_template_search_rect` | 搜索 ROI（橙框，运行时在这块里找模板） |
| `roi_template_match_threshold` | 匹配分数阈值，默认 `0.7`，越高越严 |
| `roi_template_angle_range` | 允许旋转的 ± 角度，默认 `15` |
| `roi_template_angle_step` | 角度步进。`0` 表示自动 |

`config_schema_version` 必须是 `4`。

### 三种模式

- ROI 打开：不看顺序。识别 ROI 里每个类别的数量必须刚好等于 `category_counts`。此模式不画手部骨架，也不用动作模型。
- ROI 关闭且步骤顺序关闭：按 `category_names` 做原来的 YOLO 步骤检测。手部骨架只显示。
- ROI 关闭且步骤顺序打开：只认连续 LSTM 的完整动作。配置里的动作名称必须和模型包里的非空闲动作完全一致，每步数量必须是 1。动作要看到结束边界才结算；这段里契约要求的零件都出现过才 PASS，缺一件立刻 NG。没有合格模型包时不能开始检测，也不会退回 YOLO。

准备模型包时复制训练轮次，并给一份已经核对过的编号到名称映射，不要覆盖原来的训练目录：

`python tools/prepare_lstm_bundle.py 训练轮次目录 新的模型包目录 --mapping 映射.json`

模板文件和配置放在同一目录：

- `locator_template.png` — 创建模板时裁出的图
- `locator_model.npz` — 形状模型

路径写在 `roi_template_path`、`roi_template_model_path`，一般不用改文件名。

框的坐标是归一化矩形，例如：

```json
"roi_template_rect": { "x": 0.32, "y": 0.28, "w": 0.18, "h": 0.22 }
```

`x` / `y` 是左上角相对整图的比例，`w` / `h` 是宽高比例。相机或镜头变了，这些框和模板都要重新做。

三种 ROI 彼此独立，不要求重叠或互相包含。搜索框必须明显大于模板，给工件停位留平移余量，否则开始检测会被拦住。

---

## 2. ROI 区域怎么创建模板

模板不是手写进配置的，而是用当前相机画面框一块「模板 ROI」，保存时程序自动裁图、建模型、回查。成功后才写入上面的模板文件和 `roi_template_rect`。

1. 打开相机，进配置里的 ROI 页，先刷新画面。没有静图不能建 ROI。
2. 选 **模板 ROI**，框住一个轮廓清楚、位置相对固定的定位目标（螺丝、铭牌、工件特征即可）。拖框移动，右下角缩放。
3. 点 **保存当前 ROI**。程序只用这块框裁图并在附近回查，不要求搜索 ROI、识别 ROI 已经配好。
4. 成功：静图上出现绿框和创建得分，并写出 `locator_template.png`、`locator_model.npz`。失败：旧模板和旧配置不动，换一块轮廓更清楚的再存。
5. 同样方式保存 **识别 ROI**（统计数量的区域）和 **搜索 ROI**（运行时找模板的范围）。下拉选哪种就只存哪种。
6. 把 `roi_inspection_enabled`、`roi_template_enabled` 打开，再保存整份配置。

运行时：每帧只在搜索 ROI 里做边缘匹配；命中后才对整图跑 YOLO，再用识别 ROI 判类别和数量。

相机位置、镜头或视野变了，三种 ROI 和模板都要重新框、重新保存。
