## ADDED Requirements

### Requirement: 第一类别区域模式不得追踪产品身份
系统在启用第一类别区域判定时 SHALL NOT 生成、匹配、续接、显示或依赖父类别产品 `track_id`。父类别检测只 SHALL 用于当前判定帧的区域归属，不得把产品身份或判定状态通过追踪 ID 延续到下一轮。

#### Scenario: ONNX 父类别没有原生追踪 ID
- **WHEN** 当前帧识别到没有原生 `track_id` 的第一类别父区域
- **THEN** 系统直接使用该帧父区域执行后续类别归属，不生成合成追踪 ID

#### Scenario: 检测结果带有原生追踪 ID
- **WHEN** 当前帧第一类别检测结果包含上游 `track_id`
- **THEN** 第一类别区域判定不得使用该 ID 选择轮次、继承状态或显示产品身份

### Requirement: 第一类别必须继续作为后续类别的父区域
系统 SHALL 先识别配置中的第一个有效类别作为父区域，再只对归属于当前父区域的后续有效配置类别执行数量和步骤判定。取消追踪 ID 不得改变父子区域归属规则。

#### Scenario: 父区域内识别到后续类别
- **WHEN** 当前帧识别到第一类别父区域，且后续配置类别位于该父区域内
- **THEN** 系统按照现有父子归属和配置数量推进当前轮次判定

#### Scenario: 没有识别到第一类别
- **WHEN** 当前帧只识别到后续类别但没有识别到第一类别父区域
- **THEN** 系统不得使用这些后续类别推进当前轮次判定

#### Scenario: 后续类别位于父区域外
- **WHEN** 当前帧同时识别到第一类别和后续类别，但后续类别不归属于父区域
- **THEN** 系统不得把该后续类别计入父区域的配置数量

#### Scenario: 画面存在多个父区域
- **WHEN** 当前帧识别到多个有效的第一类别父区域
- **THEN** 系统继续使用现有多父区域处理和轮次选择行为，不得新增“必须正好两块”或左右位置规则

### Requirement: 现有判定与反馈语义必须保持不变
系统移除产品追踪 ID 后 SHALL 保持现有类别数量、PASS 稳定帧、NG 稳定帧、类别完成锁存、PASS/NG 反馈、声音、证据和界面显示行为。除追踪 ID 外，不得新增或修改生产配置语义。

#### Scenario: 类别数量达到现有 PASS 条件
- **WHEN** 父区域内后续类别按照现有规则达到配置数量和 PASS 稳定帧门槛
- **THEN** 系统按照现有行为锁存类别完成并产生相应 PASS 结果

#### Scenario: 类别数量达到现有 NG 条件
- **WHEN** 父区域内后续类别按照现有规则达到 NG 稳定帧门槛
- **THEN** 系统按照现有行为产生 NG、声音和证据，不因取消追踪 ID 改变反馈规则

#### Scenario: 现有配置文件被加载
- **WHEN** 程序加载包含类别、数量、稳定帧和完成一轮间隔的现有配置文件
- **THEN** 系统继续使用这些字段且不要求新增 ROI、双板数量、相机裁剪或节拍字段

### Requirement: 完成一轮间隔必须隔离相邻轮次
系统 SHALL 继续使用现有“完成一轮间隔（秒）”保持本轮结果。间隔到期后，系统 MUST 清空上一轮类别进度、稳定帧、PASS/NG、反馈去重和父区域关联状态，再从当前检测结果开始全新轮次。

#### Scenario: 一轮完成后处于显示间隔
- **WHEN** 当前轮次按照现有规则完成并进入配置的显示间隔
- **THEN** 系统保持现有结果显示，且不得在间隔内启动下一轮

#### Scenario: 完成一轮间隔到期
- **WHEN** 当前轮次的显示间隔到期
- **THEN** 系统删除上一轮全部判定状态，并允许当前识别到的第一类别父区域从空状态开始下一轮

#### Scenario: 新 PCB 出现在旧 PCB 相近位置
- **WHEN** 间隔到期后新 PCB 出现在上一轮 PCB 的相同或相近画面位置
- **THEN** 系统不得继承上一轮类别完成状态或 PASS/NG，必须把它作为新一轮父区域处理

#### Scenario: 操作员调整完成一轮间隔
- **WHEN** 操作员根据输送速度修改现有“完成一轮间隔（秒）”
- **THEN** 后续完成轮次使用新的间隔值，系统不自动估计或增加其他节拍参数

### Requirement: 追踪 ID 不得出现在第一类别区域运行界面
系统 SHALL 在第一类别区域判定模式下隐藏产品追踪 ID，并 SHALL 保持检测框、类别、数量、步骤状态和结果显示不受影响。

#### Scenario: 第一类别区域正在判定
- **WHEN** 当前画面识别到第一类别父区域和后续类别
- **THEN** 界面显示现有检测和判定信息，但不显示产品追踪 ID

#### Scenario: 普通动作模式运行
- **WHEN** 第一类别区域判定未启用
- **THEN** 系统保持普通动作模式的现有行为，本变更不得改变其检测和显示逻辑
