## Why

当前第一类别区域检查把类别列表中的第一项当作父区域，必须先识别完整 PCB，再按父区域归属统计后续类别。现场同时出现多块外观相同 PCB 时，完整 PCB 检测可能只保留一个目标，父区域和位置槽逻辑也增加了不需要的产品身份与调度复杂度；固定机位更适合用可配置定位类别触发固定 ROI 内的通用类别数量检查。

## What Changes

- **BREAKING**：删除“第一类别作为父类”的区域检查模式、PCB 父子归属、位置槽、产品 ID/追踪以及全部旧配置字段和兼容读取。
- 新增通用“ROI 定位检测”模式开关；关闭时普通动作检测保持不变，开启时所有有效配置类别平级并行判定。
- 新增独立 ROI 配置页面，通过相机最新静态帧创建一个定位 ROI 和一个识别 ROI；矩形区域以归一化坐标保存，并支持刷新、选择、移动、缩放、删除和按类型替换。
- 新增手动填写的定位类别和精确“定位目标数量”；待检类别同样保持手动填写。配置页不从启动时已加载的模型填充或校验类别，保存新模型路径后再切换处理器；开始检测时才按实际加载模型严格核对类别名称。当前帧定位类别中心落入定位 ROI 且数量恰好匹配时，单帧立即触发本轮，并从同一帧开始识别。
- 识别阶段只统计中心落入识别 ROI 的配置类别；每个类别必须精确匹配配置数量，按现有 PASS/FAIL 帧数分别推进和锁存，所有类别 PASS 后整轮 PASS，任意未完成类别达到 FAIL 帧数后整轮 FAIL。
- 定位类别允许同时作为普通待检类别，但作为普通类别时只统计识别 ROI 内的检测结果，不把定位 ROI 的触发结果自动带入。
- PASS 或 FAIL 都结束当前轮并生成一次统计、声音和证据；现有“完成一轮间隔”是唯一的新旧轮次边界，间隔到期后清空状态并允许当前画面重新定位触发，不要求定位目标先离开。
- 主画面显示不同颜色的定位 ROI、识别 ROI、定位数量以及各配置类别的数量和状态。
- 新配置不迁移旧字段；旧配置或缺少定位类别、目标数量、任一 ROI、有效类别时允许程序打开，但必须阻止开始检测并列出具体无效项。其他电脑重新复制完整新版便携目录并重新配置。

## Capabilities

### New Capabilities

- `roi-localized-category-inspection`：定义模型类别单帧定位触发、双固定 ROI、平级类别精确数量与稳定帧锁存、整轮 PASS/FAIL/间隔重置、ROI 配置界面及强配置校验。

### Modified Capabilities

无。正式规格目录尚未包含第一类别区域检查能力；本提案取代未归档变更 `add-first-category-region-check` 和 `replace-pcb-tracking-with-fixed-cycle` 的父区域方案，但不修改普通动作模式和现有正式模型热重载规格。

## Impact

- `yolo_action_detection/src/config.py` 与默认配置：删除第一类别/PCB 专用字段，新增配置版本、ROI 模式、定位类别、定位目标数量和两个归一化矩形区域；旧配置明确不兼容。
- `yolo_action_detection/src/pcb_inspection/`：删除父区域/位置槽实现，替换为不含产品身份的 ROI 定位轮次引擎或等价通用模块。
- `yolo_action_detection/src/ui/`：用“ROI 定位检测”替换旧模式入口，新增 ROI 配置页面、静态帧绘制编辑器、运行时双 ROI 与数量状态显示。
- `yolo_action_detection/src/main.py`、相机推理结果与静态图片验收：按同一组归一化 ROI 和检测框中心规则执行定位与数量判定。
- `yolo_action_detection/tests/`：删除旧父区域语义测试，新增定位精确数量、同帧启动、ROI 边界、平级类别锁存、FAIL、间隔重置、配置拒绝、普通模式回归及 UI 编辑覆盖。
- 打包默认配置、中文 README 和 DOCX 操作手册：改为新版 ROI 配置流程；重新打包并执行真实便携冒烟，现场重新配置并验证输送节奏。
